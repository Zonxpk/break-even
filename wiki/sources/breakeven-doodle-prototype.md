# Source: เบรค, อีเวน — Doodle prototype

Single-file HTML/CSS/JS design prototype demonstrating the **Doodle** (sketchbook) visual language for the When? (กี่โมง?) app. Self-contained: inline `<style>`, an SVG `<defs>` with the wobble filters, four toggleable phone screens (Home / Order / Track / Payoff), and a small tab-switch script.

Archived to `.raw/designs/breakeven-doodle-2026-06-28.html` (the Downloads copy is ephemeral). The file also contains an unrelated `trust-wallet-one-tap` CSS block injected by a browser extension — ignored.

Synthesized into → [[concepts/doodle-design-language|Doodle Design Language]].

## What it provides

- Full crayon/paper token palette and `Mali` typeface choice
- The hand-drawn border technique (SVG `feTurbulence` + `feDisplacementMap`)
- Four representative screens with parody copy and the never-arrives payoff loop
